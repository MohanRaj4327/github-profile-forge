# GitHub Profile README Prompt Generator 🚀

A beginner-friendly, single-page web app built specifically for college students and freshers. 

It fetches a student's GitHub public information, lets them highlight up to 4 top projects, and automatically crafts an intelligent prompt for **ChatGPT**. Once pasted into ChatGPT, it returns a stunning, professional, and personalized `README.md` for their special GitHub profile repository.

---

## 📁 What Each File Does
* `index.html`: The structure of the website, containing all input fields, buttons, the 4-step tutorial, and the snake workflow guide.
* `style.css`: The look and feel of the site, featuring a sleek modern developer dark theme with emerald green accents that looks great on mobile phones and laptops.
* `script.js`: The brain of the website, handling GitHub API calls, repository filtering, max-4 project limits, prompt generation, and copy-to-clipboard functionality.

## 🌐 How to Host It Online for FREE on GitHub Pages (One Click at a Time)
Follow these exact steps to get a free live web link (e.g., `https://yourusername.github.io/readme-generator`) to share on Instagram or LinkedIn:

1. **Log in to GitHub**:
   Go to [github.com](https://github.com) and log into your account.
2. **Create a New Repository**:
   - In the top-right corner, click the **`+`** icon and select **New repository**.
   - Under **Repository name**, type `readme-generator` (or any name you like).
   - Ensure the repository is set to **Public**.
   - Do **NOT** tick "Add a README file" (we already have our files ready).
   - Click the green **Create repository** button.
3. **Upload the Project Files**:
   - On the new repository page, click the link that says **uploading an existing file**.
   - Drag and drop `index.html`, `style.css`, and `script.js` (and `README.md` if you wish) into the upload box.
   - Scroll down and click the green **Commit changes** button.
4. **Enable GitHub Pages**:
   - In your repository, click the **Settings** tab at the top.
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment** &rarr; **Branch**:
     - Change the dropdown from `None` to **`main`** (or `master`).
     - Leave the folder as `/ (root)`.
     - Click **Save**.
5. **Get Your Live Link**:
   - Wait about 1 to 2 minutes and refresh the page.
   - At the top of the Pages screen, you will see a banner:
     *"Your site is live at https://yourusername.github.io/readme-generator"*

## ▲ How to Deploy for FREE on Vercel (One Click at a Time)
Vercel is super fast and gives you a clean `.vercel.app` link. Because our project is pure HTML, CSS, and JavaScript, Vercel requires **zero configuration**!

1. **Sign Up / Log In to Vercel**:
   - Go to [vercel.com](https://vercel.com).
   - Click **Sign Up** (or Log In) and choose **Continue with GitHub**.
2. **Import Your GitHub Repository**:
   - On your Vercel Dashboard, click the blue **Add New...** button and select **Project**.
   - You will see a list of your GitHub repositories. Find your `readme-generator` repo and click **Import** next to it.
3. **Deploy (Zero Settings Needed!)**:
   - You will see a page called "Configure Project".
   - You do **NOT** need to touch anything (leave Framework Preset as "Other", leave Build and Output settings empty).
   - Click the blue **Deploy** button.
4. **Celebrate!**:
   - In about 10 seconds, confetti will burst on screen!
   - Vercel will give you a live URL like:  
     `https://readme-generator-yourname.vercel.app`
   - Every time you change code on GitHub, Vercel will automatically update your live site!
   - You can now open this link on your phone and share it anywhere!
