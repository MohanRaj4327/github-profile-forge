Step 4

Add the Contribution Snake Game (Super Cool!)

A snake that eats your green GitHub contribution dots! Uses free GitHub Actions.

1
Create the workflow file

In your profile repo, click Add file → Create new file. In the name box, type: .github/workflows/snake.yml

2
Enable Read & Write permissions

In your repo: Settings → Actions → General → scroll to Workflow permissions → select Read and write permissions → Save.

3
Run it once

Go to the Actions tab → click Generate Snake Animation on the left → click Run workflow. In 30 seconds, your snake appears!

.github/workflows/snake.yml
✔ Copied! 
name: Generate Snake Animation

on:
  # Runs automatically every 12 hours
  schedule:
    - cron: "0 */12 * * *"
  
  # Allows you to manually trigger it from the Actions tab anytime
  workflow_dispatch:
  
  # Runs on every push to the main branch
  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      # Step 1: Checkout repository files
      - name: Checkout repository
        uses: actions/checkout@v4

      # Step 2: Generate the contribution snake animation
      - name: Generate Snake Files
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      # Step 3: Push the generated SVG animation to the 'output' branch
      - name: Deploy snake SVG to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
